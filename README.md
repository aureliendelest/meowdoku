# meowdoku
SAT solver based on the DPLL algorithm, applied to solving Meowdoku, a logic puzzle where cats are placed on a colored grid. Includes a Meowdoku-to-DIMACS CNF encoder, a grid generator, several branching heuristics (e.g. Jeroslow-Wang, MOMS) and performance benchmarks. CentraleSupélec M2 AI project.
